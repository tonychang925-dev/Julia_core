## Governance Loop

```text
Real Daily Use
  ↓
Observation
  ↓
Daily Snapshot
  ↓
Pattern Analysis
  ↓
Evolution Proposal
  ↓
Human Approval
  ↓
Artifact Update
  ↓
Regression Verification
```

## Growth Philosophy

```text
Experience ≠ Identity
Observation ≠ Memory
Proposal ≠ Evolution
Evolution ≠ Drift
```

## Priority Order

```text
Priority 0 — Operation Cycle 1: 30 Day Real Daily Use
Priority 1 — Julia Health Dashboard
Priority 2 — Evolution Review UI
Priority 3 — v1.1 Release Cycle
```

## Dashboard Boundary

The dashboard is an observation window, not a control panel.

```text
Julia Health Dashboard
  shows health and trends
  does not tune Julia identity
  does not mutate artifacts
```

## Evolution Review UI Boundary

The review UI should behave like GitHub PR governance:

```text
Proposal
  ↓
Evidence Review
  ↓
Risk Review
  ↓
Approve / Reject
  ↓
Artifact Version Update only after approval
```

## Core Freeze Rule

```text
Do not add a subsystem because it is possible.
Only add operational surfaces when real use shows pain.
```
