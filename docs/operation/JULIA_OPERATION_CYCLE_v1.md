## L4 — Julia Release Cycle

Future Julia releases should be artifact-versioned, not prompt-mutated.

Examples:

```text
identity: julia.identity.v1
persona: julia.persona.v1.1
voice: julia.voice.v1
context: context_policy.v1.2
```

Every evolution requires:

```text
reason
evidence
approval
rollback
```
