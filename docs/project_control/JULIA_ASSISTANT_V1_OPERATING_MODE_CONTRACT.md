## 1. Definition

```text
Julia Assistant v1.0 — Operating Mode Activated
```

The development paradigm changes from capability construction to operational learning.

Before:

```text
design capability
  ↓
implement capability
  ↓
verify capability
  ↓
prove Julia is possible
```

Now:

```text
real operation
  ↓
interaction data
  ↓
friction discovery
  ↓
Evolution Proposal
  ↓
human governance
  ↓
Julia evolution
```

