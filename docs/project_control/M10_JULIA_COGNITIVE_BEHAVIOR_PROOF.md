M10 proves that Julia is not only recoverable, but can understand, plan, select context, and support natural expression before provider language generation.

```text
M8: Julia Identity & Behavior Proof
M9: Julia Continuity Proof
M10: Julia Cognitive Behavior Proof
```

- K8.2 Response Intention Planning PASS
- K8.3 Context Need Optimization PASS

```text
Julia can understand Tony's current meaning, decide the intended interaction, select relevant continuity context, constrain expression boundaries, and produce human-recognizable natural Julia behavior through a provider.
```

## Non-Claim

M10 does not prove long-term operation or future evolution. J0 remains required.
