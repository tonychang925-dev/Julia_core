# Memory API v1.0 — FROZEN

## Principle

Memory stores experience. Context OS assembles current context.
They are orthogonal.

## Rules

- Memory does NOT replace Context OS.
- Provider output does NOT auto-become memory.
- Memory requires explicit governance (classification, retention, protection).
- Private memory data lives outside the public julia_core repository.

FROZEN. Memory ≠ truth. Memory ≠ context.
